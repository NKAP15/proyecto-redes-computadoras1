
# Proyecto Final - Redes de Computadoras I
## Descripción
Proyecto académico de diseño y simulación de una red empresarial desarrollado en Cisco Packet Tracer.
El proyecto implementa diferentes tecnologías y servicios de red para establecer comunicación entre distintas regiones y departamentos de la organización.

## Tecnologías y conceptos

- Cisco Packet Tracer
- VLAN
- DHCP
- Enrutamiento
- RIP v2
- EIGRP
- VoIP
- Telefonía IP
- Configuración de switches y routers
- Direccionamiento IPv4
